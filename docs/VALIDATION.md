# Local validation

Date: September 21, 2026, Pacific. Node 26.7.0, macOS. No CI success or external deployment is claimed.

- `npm test`: **21 / 21 passed**, including 19 official BIP-340 verification vectors in one vector test and three actual WebSocket integration tests.
- `npm run build`: TypeScript check and production Vite bundle passed.
- `npm run replay`: 20 cases; 11 admits, 1 quarantine, 7 rejects, 1 duplicate, 7 retained.
- `npm run verify`: replay of serialized evidence passed; content digest recorded in generated evidence, not hardcoded as a lasting claim here.
- `npm audit` at installation: zero known vulnerabilities.

Tests exercise wire field tampering, malformed envelopes/points, genuine UTF-8 budgets, inclusive time bounds, arrival-based rate limit edge, duplicate budget preservation, replacement order/tie behavior, author and address isolation, deletion-before-arrival, inability to delete a deletion request, exact filters and live `limit:0`, payload limits, Origin/path rejection, and forged evidence with a recomputed outer hash.

Raw protocol messages in WebSocket tests are generated by separate client sockets and traversed through the actual loopback server. UI prediction and server share the core reducer; protocol semantics are also asserted directly. Passing these tests does not make this a production relay.
